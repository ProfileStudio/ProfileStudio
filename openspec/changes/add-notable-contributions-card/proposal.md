# Proposal

## Why

Contributions to other people's projects are often a developer's strongest signal, and the profile shows only their own repositories.

## What Changes

- Optional card listing repositories the user contributed to (merged pull requests or commits), outside their own account, ranked by the repository's popularity.

## Capabilities

### New Capabilities

- `notable-contributions`: Card with repositories the user contributed to outside their own account.

### Modified Capabilities

None.

## Impact

GraphQL query for contributed repositories and merged pull requests; new card.

## Out of Scope

- Private repositories.

## Prior Art

metrics' notable plugin (MIT). Idea only.
