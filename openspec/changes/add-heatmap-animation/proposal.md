# Proposal

## Why

Animated contribution graphs are a favorite profile element, but the best known one has no license and none follow the profile's theme.

## What Changes

- An original, optional animation over the contribution heatmap drawn in the theme's style (for example cells lighting up week by week), CSS only.

## Capabilities

### New Capabilities

- `heatmap-animation`: Optional original animation of the contribution heatmap.

### Modified Capabilities

None.

## Impact

Activity card, `profile.json` key `heatmap_animation`.

## Out of Scope

- Reproducing another project's animation or look.

## Prior Art

Inspired by the popularity of animated contribution graphs; no code or design is reused.
