# Design

## Context

Platane/snk has no license: nothing from it may be copied, and the result must not look like it.

## Goals / Non-Goals

**Goals:**
- An animation that belongs to ProfileStudio.

**Non-Goals:**
- A snake or pac-man game.

## Decisions

- Candidate concepts: weekly sweep, rising columns, theme-specific effects (CRT scan, git graph).

## Risks / Trade-offs

- File size growth on large calendars: cap keyframes.
