# Proposal

## Why

Users without Claude Code must edit JSON by hand. Visual editors are the most popular entry point in this space.

## What Changes

- Turn `preview.html` into a local editor: forms for every `profile.json` key, live theme switching and copy-ready output, with no server.

## Capabilities

### New Capabilities

- `visual-editor`: Local browser editor for profile.json with live preview.

### Modified Capabilities

None.

## Impact

New static editor page, card metadata reuse, docs.

## Out of Scope

- A hosted service or accounts.

## Prior Art

rahuldkjain (Apache-2.0), maurodesouza (MIT) and github-stats-extended's wizard (MIT). Idea only.
