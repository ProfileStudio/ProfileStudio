# Proposal

## Why

Some developers publish their best work as gists, which the selected work section cannot show.

## What Changes

- Allow a gist as a selected work item, drawn like a project card.

## Capabilities

### New Capabilities

- `featured-gists`: Gists as selected work items.

### Modified Capabilities

None.

## Impact

Project card data fetching, `projects` entries with `gist`.

## Out of Scope

- Embedding gist code.

## Prior Art

github-stats-extended (MIT) has gist cards. Idea only.
