# Proposal

## Why

The language card has one layout. Compact profiles want a smaller donut or a two-column list.

## What Changes

- Layouts for the language card: bars (current), compact two columns, donut.

## Capabilities

### New Capabilities

- `language-layouts`: Alternative layouts for the language stack card.

### Modified Capabilities

None.

## Impact

Language card, `profile.json` key `languages_layout`.

## Out of Scope

- New language data sources.

## Prior Art
